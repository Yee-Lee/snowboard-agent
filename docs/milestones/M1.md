# M1 規劃

## 3. M1 ── 純軟體核心

### 3.1 範圍

* 建立 Python package 與測試骨架。
* 實作 Ch 2 的 lifecycle 控制值與 InputSource / Perception / Action / Adaptor Protocol ；具體 worker / backend 留 M2。
* 實作 Ch 1 的事件 dataclass、型別與識別符。
* 實作 Ch 3 的 direct-call Event Bus、subscription token、延後 error fallback、fatal latch 與 `wait_fatal()` 。
* 實作 Ch 4 的 inbox、guard、session / turn、in-flight record、Fact + task-done join、狀態轉移與 private notice。
* 實作 Ch 5 的 registry preflight、phase + DAG、scoped resolver、startup rollback、WorkerCatalog、capability map 固化、recovery ticket 與 reverse stop。
* 實作 Ch 6 的 Level 1 / 2 / 3 收斂與 ForceAbortReport 聚合。
* 實作 Ch 10 的 immutable schema、strict YAML / env loader、example files 與 cross-field validation。
* 實作 Ch 11 的 logger、canonical ErrorOccurred observer、redaction、fatal supervision 與 exit code。
* `main.py` 完成 bootstrap 與 supervision 接線；本階段允許使用測試 fake 裝配驗證，不要求具備完整對話 worker。
* 在 pytest 設定註冊 `rpi` marker，使開發機與 Pi-only 驗收可明確分流；測試分流區分 Windows portable suite（純 Python / mock / config / portable subprocess stream）與 Linux process 權威驗證（POSIX SIGINT/SIGTERM 處理與原生 lifecycle），禁止為 Windows 修改 production signal architecture。

### 3.2 相依

* §1.2 Developer 進場 gate 已完成。
* M1 / M2 驗收對照已寫入 `docs/test_spec.md` 。
* `pyproject.toml` 的測試依賴可在 Python 3.11 開發環境安裝。

### 3.3 排除項目

* 不實作 ASR、TTS、Vision、LiteRT-LM 或任何真實 worker backend。
* 不實作真實 audio / display / camera / GPIO driver。
* 不要求 mock 對話從 wake 跑完整個 session；該垂直切片屬 M2。
* 不建立 MQTT、wake daemon 或跨 process wire schema。
* 不修改 `arch.md` 的模組邊界或事件集合。

### 3.4 可重複驗收

1. 執行：

```bash
python -m pytest -v tests/milestones/test_m1_foundation.py
python -m pytest -v
```

2. `test_m1_foundation.py` 至少證明：
* Event immutable / nested payload 唯讀慣例及 ID 生成符合 Ch 1。
* Event Bus exact-type、snapshot、派送順序、fallback 與 fatal latch 符合 Ch 3。
* SM 只有 terminal Fact 與 outer task done 都成立才前進；stale / duplicate 不污染狀態。
* RM 在碰資源前拒絕非法 graph ；啟動、rollback、capability map 固化與 recovery barrier 的順序可由 call log 重現。
* 多 worker Level 1 平行；Level 2 不呼叫 outer `task.cancel()` ；Level 2 timeout / raise 產生 `ConvergenceFatalError` 。
* config default、strict overlay、env precedence、secret redaction 與 example YAML 均通過同一 loader。
* config / startup / runtime fatal 分別映射 exit code 2 / 3 / 4 ；正常 shutdown 為 0。

3. 測試不得 import `sounddevice` 、 `picamera2` 、 `gpiod` 、 `LiteRT-LM` 或連接網路 / 硬體。
