# Archived Audio POC Planning Material

本目錄只保存先前 Audio POC 的 milestone 計畫與 gate 記錄，供歷史追溯。

它們不是目前 LLM POC 的活動計畫、entry condition、hardware result 或 delivery
authority。LLM POC 的唯一狀態入口是
[`docs/milestone/README.md`](../../milestone/README.md)。

M4a Audio HAL 只會在 LLM M4 作為已由產品流程 Accepted 的外部 dependency；本 LLM
POC 不接手 VAD、ASR、TTS、co-I2S 或 Audio HAL candidate 工作。
