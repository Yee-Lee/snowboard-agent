## 1. Designer-owned contract

Reasoner provides SessionFacts and current TurnInput, receives SemanticGeneration(text,end), checks available capabilities and emits exactly one canonical speak/listen or rest result. There is one model call per turn. Core envelopes and diagnostic JSON are generated by software, never by the model. POC projection is an oracle, not the production Reasoner.

Compare exactly two model encodings:

- J: existing exact `text/end` constrained JSON and Python relation validation.
- P: UTF-8 `S\n<nonblank text>` or exactly `E` followed by normal generation termination. No BOM, leading whitespace, markdown fence or additional control field. The S body is ordinary text, including literal S/E characters; it is never reparsed as control. E with trailing bytes is invalid. No repair/retry. EOS is runtime termination, not a string to generate.

Keep name/role/locale/capabilities, public questions, temperature=0, top-p=1, CPU/4 and 32 new-user / 128 output / 1024 KV fixed. Only the instruction describing output encoding changes between J/P. POC freezes exact prompt bytes, supported grammar and tokenizer counts before measured execution. Do not compare different answer budgets or introduce prompt tuning. If the selected runtime cannot constrain P reliably, return `UNSUPPORTED` with the exact rejected feature and retain J; do not invent another candidate.

Both decoders return the same internal text/end. P incremental parser buffers until the complete S newline prefix; emits body text only afterward. E emits no speech and becomes end=true only after successful terminal. Invalid prefix, invalid UTF-8, overflow, missing terminal or cancellation produces no successful result and closes dirty context. Tests split the prefix, UTF-8 and body at every representative boundary; inject E-plus-text, blank S, unknown prefix, truncation and cancel before/after the first text fragment. Assert no action after failure and no old-session output in a new session. No real TTS in this task.

For future streaming, text is provisional until terminal: an invalid terminal after released text requires downstream cancellation and session end, never retroactive success. Measure this limitation explicitly. Reasoner retains authority over a single speak operation and session end; chunks cannot dispatch tools or create extra turns.

## 2. Independent experiments

First prove bounded selected-runtime import, load, grammar, one output, same-Conversation follow-up and close; report immediately. A missing API stops only its dependent experiment.

### A: encoding

Use the 001 public timing pair: `天空為什麼是藍色的？`, then `再簡單一點。`. Prewarm=none; establish the same same-boot conditions for both. Run five paired fresh-child repetitions in fixed order J1/P1 … J5/P5, with five idle seconds between children. No cache dropping. Record cache state and do not label these cold results. Each session has two turns and closes.

Report each sample plus median/range: session open, runtime TTFT/TTC, caller TTC, first decodable text, first punctuation-or-24-Unicode-codepoint chunk, input/rendered/incremental/KV/output counts, owner PSS and cleanup. Separate frame overhead using the selected tokenizer with a fixed public body; do not subtract overhead timing from measured TTC or equate it to speakable characters. Natural answer differences remain a limitation of the comparison. Public explicit-end and negative-end cases are frozen before execution; record model intent errors separately from parser defects, without tuning to the outcomes.

### B: clean Conversation readiness

Use J only to isolate lifecycle from encoding. Compare on-demand open against open-before-request then hold for exactly 30 seconds, both without prewarm. Five paired fresh-child same-boot repetitions, D1/H1 … D5/H5; identical public timing pair, cache policy and idle interval as A. Report startup-to-engine-ready, interaction-ready, request arrival-to-first-text/full-result, holding PSS, close and cleanup separately. Account for all preparation time; do not hide it by renaming READY.

On-demand J samples from A may be referenced only if all conditions and planned identities match; declare reuse before execution, otherwise run independent D rows. Do not retain the greeting prewarm Conversation or transfer its history. Additional bounded checks: no request during hold then close; cancel during open; end then new session; capability/facts mismatch refuses adoption. Verify no history inheritance and at most one live Conversation.

Cold/once-prewarm results from DELIVERY-025 remain contextual evidence, not new matched comparison data. No new reboot matrix or Audio integration is requested.
