## 3. Persistent Child 契約與可觀察要求

Contract 已將下列 Core production 契約納入 POC 驗證清單（M4B-P1, P5, P6, P7, P8）：

1. **READY Handshake**：子行程啟動後於 10s 內發送 READY frame；未 READY 前不派發推論請求。
2. **Single-turn Generate & Result**：支援 structured JSON / intent 格式輸出；無 prompt 洩漏或亂碼。
3. **Timeout & Clean Interruption**：超時（如 15s）可主動觸發中斷，不卡住行程。
4. **Cooperative Cancel**：支援中斷訊號，Child 於 500ms 內安全中止生成並恢復 READY。
5. **Force Abort (SIGTERM/SIGKILL + waitpid)**：驗證非同步強制終止與 process reap，無 zombie/orphan 殘留，確保 Resource Manager recovery barrier 可靠性。
6. **History Isolation**：嚴格驗證單 turn 獨立性，跨 session / turn 無殘留 KV cache 或 context pollution。
